# 2026-09-10 模型演示基线

此版本保存已由用户确认可用的模型演示，作为下一阶段三维位置引导 YOLO 的回退基线。
发布分支为现有 `feature/simulation`。模型演示本身不运行 YOLO。

## 保存内容

- 正式隧道模型的十处病害映射、表面投影及静态遮挡判断。
- 同一巡检中，同一物理病害跨相机、跨帧更新同一条记录。
- 平台报告坐标和 RViz 红点、历史会话、Qt 打印及 PDF 导出。
- Qt 接入已有后台，避免重复启动导致端口冲突；相机暂时未更新保留最后一帧。
- 速度指令、必需传感器超时停车及退出处理。
- 独立岔轨测试世界、小车和选路平台，保留独立端口与 ROS 域；删除已废弃的旧模型。

## 在另一台电脑复现

1. 按仓库 README 安装依赖，在 `feature/simulation` 分支执行 `git lfs pull`。
   隧道 DAE 使用 Git LFS，不能只下载到指针文件。
2. 按 [模型演示说明](model_annotation_demo.md) 安装 `pycollada`、`trimesh`、`embreex`。
3. 在新机器上重新执行 `colcon build --symlink-install`，不要复制旧机器的构建产物。
4. 打开 Qt，在运行设置中启用“模型标注演示（使用模型位置）”，保存并启动。
   此模式不需要 YOLO 权重，也不自动行驶。
5. 本机访问 `http://127.0.0.1:8088`。Tailscale 需要在实际主机上另外配置 Serve
   指向本机 8088；本机地址和 Tailscale 地址可同时使用。开启系统代理的设备需将
   该主机的 Tailscale 域名加入代理绕过列表。

Git 保存源码、配置和模型资源；本机 SQLite 历史记录、视频、权重、日志与诊断报告
不包含在这次提交中。启动后生成新的巡检记录。

- 发布前相关 Python/Qt 测试：122 项通过，2 项跳过。
- 实际 Qt 页面点击打印按钮，可导出包含当前八条记录及坐标的 A4 横向 PDF。
- 本机 HTTP 和 Windows Tailscale HTTPS 的页面及健康接口访问成功。
- 实体打印机、队友电脑和长时间连续运行仍需各自验收；本说明不将单机测试结果
  扩展为所有环境均稳定的保证。

模型参考坐标与视觉预测坐标保持区分。后续 YOLO 引导试验应独立验证候选区域内
的模型输出，不能把已知类别或模型坐标当成 YOLO 的识别、定位准确率。
